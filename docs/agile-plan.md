# Agile Plan

## Sprint 1: Foundation
Oracle schema, Maven WAR, authentication, branch policy, CI package check.

## Sprint 2: Ticket intake
Ticket form, validation, priorities, BLOB attachment storage, user ticket view.

## Sprint 3: Resolution operations
Technician dashboard, aggregate counts, self-assignment, comments, status transitions.

## Sprint 4: Quality and delivery
Feedback, reports, API tests, JSP UI tests, security review, Docker/Tomcat deployment and demo.

Definition of done: acceptance criteria tested, code reviewed, database migration documented, and WAR deployed to a clean Tomcat instance.
